# Inuverse ロゴ仕様

柴犬の顔の形を「INUVERSE」の文字で作り、ハッブル・ウルトラ・ディープ・フィールドのような銀河の写った円い窓に置いたロゴ。すべての形は `scripts/brand/generate-logo.mjs` の数値から生成する。手で SVG を直さず、数値を変えて生成し直す。

```bash
node scripts/brand/generate-logo.mjs          # public/brand/ に SVG を書き出す
node scripts/brand/generate-logo.mjs --png    # PNG と favicon.ico も作る（rsvg-convert と magick が必要）
```

数値を変えたら、この文書の表も合わせて直す。

## ファイル

`public/brand/` に置く。文字はすべてパスに変換してあるので、フォントがない環境でも同じ形で表示される。

| ファイル | 内容 | 使う場所 |
|---|---|---|
| `inuverse-mark.svg` | 記号（窓・銀河・文字の柴） | アイコン、SNS のプロフィール画像、64px 以上 |
| `inuverse-mark-mono.svg` | 記号の単色版（窓と銀河なし） | 白地の印刷物、1 色しか使えない場所 |
| `inuverse-favicon.svg` | 線で描いた顔（文字と銀河なし） | favicon、32px 以下 |
| `inuverse-logo-horizontal.svg` | 記号＋ロゴタイプの横組み（白地用） | サイトのヘッダー、資料の表紙 |
| `inuverse-logo-horizontal-dark.svg` | 同上（黒地用） | 暗い背景 |
| `inuverse-logo-vertical.svg` | 記号＋ロゴタイプの縦組み（白地用） | 正方形に近い枠 |
| `inuverse-logo-vertical-dark.svg` | 同上（黒地用） | 暗い背景 |
| `inuverse-wordmark.svg` | ロゴタイプだけ（白地用） | 記号を並べられない細い枠 |
| `inuverse-wordmark-dark.svg` | 同上（黒地用） | 暗い背景 |
| `favicon-{16,32,48,180,192,512}.png`、`favicon.ico` | favicon の PNG（180 は Apple touch icon） | `--png` で生成 |
| `inuverse-mark-{256,512}.png`、`inuverse-logo-horizontal{,-dark}.png` | PNG 版 | SVG が使えない場所 |

## 作図の定義

120 × 120 の枠での値。角度は真上から時計回り（度）。

| 部品 | 定義 |
|---|---|
| 窓 | 中心 (60, 60)、半径 56 の円を Deep Field で塗る |
| 銀河 | 乱数（線形合同法、種 11）で 52 個を窓の中に置く。45% は点（半径 0.4〜1.2）、40% は楕円銀河（中心が白く外へ透ける楕円、長半径 1.2〜5.2）、15% は 2 本腕の渦巻銀河 |
| 恒星 | ハッブルの写真と同じ十字の光条を持つ星を (92, 30) と (24, 78) に置く。光条の長さは 6 と 4 |
| 頭 | 中心 (60, 64)、半径 31 の円 |
| 耳 | 円周上 ±40° を中心に ±22° の幅を底辺とし、そこから ±18° の向きに 19 離れた点を頂点とする三角形。頭と合わせて 1 本の輪郭にし、外へ 1.5 広げて角を丸める |
| 文字 | 大きさ 6.2 の「INUVERSE」を繰り返す行を、y = 20 から 5.2 おきに敷く。i 行目は左へ 40 ずらした位置から、さらに (17 × i) mod 40 だけ右へずらす。字間は 0.02 em。頭の輪郭で切り抜く |
| 裏白 | 頬の円 2 つ（中心 (48, 76) と (72, 76)、半径 14）と口先の楕円（中心 (60, 82)、半径 13 × 11）。この中の文字だけ Urajiro にする |
| 目 | 中心 (47.5, 61) と (72.5, 61)、半径 3.4 × 4 の楕円 |
| 鼻 | 上辺が y = 73 で幅 9、頂点が (60, 79) の逆三角形。角を半径 1 で丸める |

favicon は同じ頭と耳を Aka で塗り、耳の内側・裏白・麻呂眉（中心 (49, 52) と (71, 52)、半径 2.6）を Urajiro で描く。目は半径 2.8 × 3.4。

## 色

コントラスト比は WCAG 2 の式で計算した値。

| 名前 | 値 | 用途 | コントラスト比 |
|---|---|---|---|
| Deep Field | `#0a0e24` | 窓、ロゴタイプ（白地） | 白に対して 19.07:1 |
| Aka | `#d2742c` | 赤柴の毛色（記号の文字） | Deep Field に対して 5.70:1 |
| Urajiro | `#f7ead6` | 裏白、ロゴタイプ（黒地） | Deep Field に対して 16.07:1 |
| Sumi | `#1b1420` | 目と鼻 | Urajiro に対して 15.16:1 |
| Mono | `#111827` | 単色版 | 白に対して 17.74:1 |
| Mono Urajiro | `#9ca3af` | 単色版の裏白 | — |

銀河の色は `#ffb35c`・`#ff8a4c`・`#ffe2b0`（遠くて赤く見える銀河）、`#9cc0ff`・`#c9d8ff`（若い星が多く青く見える銀河）、`#ff9aa8`（星が生まれている領域）。

## 書体

[Outfit](https://fonts.google.com/specimen/Outfit)（SIL Open Font License 1.1）。生成には `@fontsource/outfit` の WOFF を使う。

| 使う場所 | ウェイト | 字間 |
|---|---|---|
| 記号の中の文字 | 900 | 0.02 em |
| ロゴタイプ | 600 | −0.01 em |

ロゴタイプは「Inuverse」（頭だけ大文字）。横組みでは文字の大きさを 56 にし、大文字の高さの中心を記号の中心にそろえる。記号との間は 20。縦組みでは文字の大きさを 34 にし、記号との間を 10 あける。

## 余白と大きさ

- 周りには、記号の直径（112）の 1/4 以上の余白をあける。
- 記号（`inuverse-mark.svg`）は 64px 以上で使う。それより小さいと文字がつぶれるので、`inuverse-favicon.svg` を使う。favicon 版は 16px でも顔が読めることを確かめてある。
- 横組みは高さ 64px 以上で使う。

## してはいけないこと

- 縦横比を変える、回す、傾ける。
- 色を上の表以外に変える。文字の色を毛色と裏白で入れ替える。
- 記号の中の文字やロゴタイプを、別の書体で組み直す。
- 窓を外した記号を、写真や柄の上に置く（単色版は無地の上だけで使う）。
- 64px より小さい場所に、銀河と文字のある記号を使う。
